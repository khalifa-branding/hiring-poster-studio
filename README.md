## 📄 Key Features
- **Guided Form-Based Left Sidebar**: Real-time form fields for letter date, recipient details, subject, salutation, body text, and signatory information (`Mohammed Saleem`, `Founder & Chairman`).
- **Live Reactive A4 Preview**: Realistic A4 paper canvas (`210mm x 297mm`) updating in real-time.
- **1-Click Microsoft Word (.docx) Exporter**: Generates native OpenXML `.docx` files with high-res 10-Year Anniversary Logo images embedded in headers and bottom-pinned 2-column tables in footers.
